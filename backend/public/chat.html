Reca is an AI study companion for WAEC & JAMB — built for AI BuildFest so students get explanations, quizzes, and recall that don’t wait for them to open the chat.

  • AI Learn — the model explains any syllabus topic in plain language, by subject.
  • AI Revise — Reca generates and grades questions; you answer one at a time.
  • AI memory — Progress tracks what’s weak and when you’re due to forget — then Reca comes first.

Generic AI chat remembers when you return. Reca’s AI decides when to resurface — on WhatsApp and in this web app.

How Reca’s AI loop works

  1. Ask the AI Open Learn, pick a topic, or type in the composer — Reca explains with the study model.
  2. Quiz with AI From Learn, try 2 quick questions — or open Revise for a 5-question session.
  3. AI remembers misses Wrong answers get a resurface time. Progress shows what’s due for recall.
  4. AI comes first Unprompted recall nudges + a daily AI briefing (days-to-exam + weakest topic) on web and WhatsApp.

Demo the AI companion fast

  • Ask Reca to explain Photosynthesis on Learn — that’s the AI explanation path.
  • Tap Try 2 quick questions — miss one on purpose so memory has something to resurface.
  • Trigger recall: wait for the nudge, or call POST /demo/resurface.
  • Daily AI briefing: POST /demo/briefing (same copy on web + WhatsApp when linked).
  • Link WhatsApp in Settings so the student id matches phone and Progress.

Sidebar should say Online when the AI API is up. If it flakes, the demo still runs on the topic bank.

What Reca stores (honest limits)

  • Your WhatsApp number is your account ID — no password.
  • Name, exam date, and theme stay in this browser until you Sign out.
  • Quiz attempts / Progress sync to the shared student record for that number.
  • There is no “forgot password.” Need in again? Returning → code on WhatsApp.
  • Lost number recovery isn’t in this build — Progress stays on the old WhatsApp.

Don’t paste real secrets or school credentials into the demo.
