# Reca web chat (student product)

Student-facing chat UI. Same memory engine as WhatsApp.

Open: **http://localhost:3000/chat.html**

## Student experience

1. Open Reca → welcome  
2. Tap a suggested topic or type `explain …`  
3. Answer the questions  
4. If you miss one, Reca comes back later on its own  

No demo chrome. Resurface is automatic (`RESURFACE_MINUTES`).

## Run

```powershell
cd backend
npm run dev
```
