# Reca pitch package

| File | Use |
|------|-----|
| [Reca-Pitch-Deck.pptx](./Reca-Pitch-Deck.pptx) | Submit / present in PowerPoint |
| [reca-pitch-deck.html](./reca-pitch-deck.html) | Present in browser · **File → Print → Save as PDF** (landscape) |
| [Reca-Pitch-Deck.pdf](./Reca-Pitch-Deck.pdf) | PDF export (generate via print or script below) |
| [DEMO-VIDEO.md](./DEMO-VIDEO.md) | Shot list for the required demo video |
| [generate-pptx.js](./generate-pptx.js) | Regenerate PPTX: `node docs/reca/pitch/generate-pptx.js` |

**Live link:** https://reca-study-companion.vercel.app/signup.html

## Judging map (10 slides)

1. Title / one-liner  
2. Problem + scale  
3. Why not ChatGPT (passive vs active)  
4. Solution  
5. Functionality & execution (loop)  
6. Use of AI  
7. Impact & usefulness  
8. Live link & demo path  
9. Why we built it  
10. What’s next / close  

## PDF from HTML (Windows)

1. Open `reca-pitch-deck.html` in Chrome  
2. `Ctrl+P` → Destination **Save as PDF**  
3. Layout **Landscape**, Margins **None**, Background graphics **On**  
4. Save as `Reca-Pitch-Deck.pdf` in this folder
