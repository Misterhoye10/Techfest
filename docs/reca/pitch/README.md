## Official judging (lead with the 50%)

| Weight | Criterion |
|--------|-----------|
| **25%** | Problem–Solution Fit — *Does it solve a real problem?* |
| **25%** | Practical Usefulness — *Can people actually use it?* |
| **20%** | Creativity & Innovation |
| **20%** | User Experience |
| **10%** | Execution Quality |

Also required for points: working build submit · **demo video upload** · community · early submit.
