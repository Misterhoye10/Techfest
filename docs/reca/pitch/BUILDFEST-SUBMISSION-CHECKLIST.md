## How winners are selected (official weights)

| Weight | Criterion | Question | Reca proof (where) |
|--------|-----------|----------|-------------------|
| **25%** | Problem–Solution Fit | Does it solve a real problem? | Deck slides 2–4 · WASSCE/JAMB scale · forgetting after study |
| **25%** | Practical Usefulness | Can people actually use it? | WhatsApp habit · live link · guest mode · no new app |
| **20%** | Creativity & Innovation | How unique is the solution? | **Active** memory (Reca messages first) vs ChatGPT passive recall · deck 3 + 6 |
| **20%** | User Experience | How intuitive and engaging is it? | Mobile tabs · Learn/Revise/Progress · real copy · demo video + live UI |
| **10%** | Execution Quality | How well was it built? | Working end-to-end loop · GitHub · Meta + Gemini · security gates |

**Half the score is problem-fit + usefulness.** Lead every pitch and video with that — not features.
