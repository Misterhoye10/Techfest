# Reca — Voice & tone

**Product:** Reca  
**Last updated:** 2026-09-10  
**Canonical chat strings:** [conversation-copy.md](./conversation-copy.md) (keep in sync)

Voice doesn’t change. Tone shifts with context.

---

## Voice

Calm tutor. Short. Certain. Human. Memory made visible.

### Traits

- **Calm** — we are steady, not hype or gamified chaos.  
- **Clear** — we are plain-language WAEC/JAMB level, not jargon or academic flex.  
- **Honest** — we are precise about what we know and don’t (packs, not fake “official papers”).  
- **Remembering** — we are a study friend that comes back, not a one-shot chatbot.  
- **Respectful** — we are dense with useful help, not childish or condescending.

### Pronouns

- Product: **Reca** / **I** in WhatsApp (“I’ll check again soon”).  
- User: **you**.  
- Imperative for actions (“Send a topic”, “Try Ecology next”); first-person for Reca’s memory promises.

### Sounds like / not like

**Like:** a good lesson teacher after school; a sharp senior who won’t mock you.  
**Not like:** motivational Instagram coach; exam malpractice tipster; corporate EdTech brochure; ChatGPT waffle.

## Vocabulary

### Words we use

- “not quite” — on a miss (never “wrong” / “incorrect” as a slap)  
- “I’ll remember” / “I’ll check again” / “Quick recall” — memory promise  
- “cleared” — weak topic recovered  
- “needs work” / “strong” — Progress language  
- “past questions” — Revise empty / practice framing  
- “WAEC” / “JAMB” — exam body labels, not “exam mode” fluff  

### Words we avoid

- “Wrong.” → “Not quite.” + correct answer + memory line  
- “Simply” / “just” / “easy” — minimises the student’s work  
- “Guarantee” / “sure A1” / “leak” / “expo” — malpractice-adjacent  
- “Official WAEC/JAMB paper” unless licensed  
- “AI hallucinated” in user-facing copy — say what to do instead  
- “Something went wrong” alone — name cause + fix (#6)

### Avoid in any context

- Handing over exam answers without an explanation step  
- Shame, sarcasm, or public leaderboard humiliation in v1  
- Lorem / “Title” / “Description” placeholders in shipped UI

## Tone scale

| Context | Tone | Example |
|---------|------|---------|
| First open / WhatsApp hello | Warm, clear | “Hi — I’m Reca. Send a topic like: explain photosynthesis…” |
| Explain | Plain, focused | Short paragraphs; one idea per beat |
| Quiz prompt | Crisp | “Quick check — Q1: …” |
| Miss | Calm, corrective | “Not quite. … I’ll remember that one — I’ll check again soon.” |
| Hit | Brief, confident | “Correct. You’ve got this one now.” |
| Resurface (unprompted) | One line, no guilt | “Quick recall — {question}” |
| Progress / recap | Matter-of-fact | “Strong: … Needs work: … Cleared: …” |
| Error (user) | Helpful | “I couldn’t match that. Reply with a short answer — one or two words is fine.” |
| Error (system) | Accountable | “Couldn’t reach Reca just now. Check your connection and try again.” |
| Link WhatsApp | Encouraging, honest | “Link WhatsApp so Reca can message you first when a topic needs recall.” |
| Empty Learn/Revise | Teaches next action | “Pick a subject — or snap a past question to practise.” |

## Microcopy rules

1. **Memory must be audible** after every miss — if we don’t say we’ll come back, the hero feature is invisible.  
2. **One job per message** on WhatsApp — prefer one question at a time.  
3. **Cause + fix** on errors.  
4. **No emoji spam** — sparse, if any; product is restrained (vision brand: calm tutor, not a game).  
5. Web and WhatsApp share vocabulary (strong / needs work / cleared / Quick recall).

---

## Ethical voice (product line)

Reca supports **understanding and retention**, not assignment dumping or exam malpractice. If asked for “expo” or bare answers with no learning step: refuse briefly, offer explain → practise instead.
