## 🚀 When to Push to PRD Branch

**BEFORE you start coding:**

1. Both developers (backend + frontend) review all docs
2. Team aligns on:
   - Feature scope (what's MVP vs stretch)
   - Role assignments
   - Tech decisions
3. Push all planning docs to `PRD` branch
4. Use `PRD` as the source of truth

**AFTER you start coding:**

- Switch to `AI-Study-Companion-backend` branch (backend dev)
- Switch to `AI-Study-Companion-frontend` branch (frontend dev)
- Don't commit code to PRD — PRD stays docs-only
